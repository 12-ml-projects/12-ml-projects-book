Make sure npm and node are installed. I personally use `v11.17.0` and `v26.5.0` respectively. TODO: create dev containers

This project uses Hugo. Scripts have been set up in `package.json` to make the development process smoother.

To run the Hugo server (and watch for changes)

